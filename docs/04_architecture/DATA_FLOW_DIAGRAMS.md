# Data Flow Diagrams

## Import Flow

`Selected File -> Quarantine -> Format Validator -> Parser -> Canonical Document -> Encrypted Source Snapshot`

## Proofreading Flow

`Unlocked Project -> Context Selector -> Local Proofreading Model -> Structured Proposal -> Validators -> User Review -> Revision Store`

## Translation Flow

`Unlocked Project -> Segment/Page Mapper -> Local Translation Model -> Structured Proposal -> Validators -> Page Review -> Revision Store`

## Export Flow

`Unlocked Project -> Explicit Confirmation -> Local Export Adapter -> Local File Handoff -> Temp Cleanup`
