# Trust Boundary Diagrams

## TB-1 File Import

Untrusted user-selected documents cross into a constrained parser boundary.

## TB-2 Vault Access

Encrypted project data crosses into bounded decrypted working memory after successful unlock.

## TB-3 AI Boundary

Authorized text excerpts cross into a local untrusted model runtime that may only return typed proposals.

## TB-4 Export

Protected internal state crosses into an external local file only after deliberate confirmation.
